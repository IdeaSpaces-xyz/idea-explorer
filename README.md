# Idea Explorer — team downloads

This is where we share early IdeaSpaces desktop builds. The first download is **IdeaSpaces Handover v3 for Apple-silicon Macs**. It is an early team build for trying the first Thread exchange, not a general release or a full installer. The app source is not in this repository.

[Download the hand-over build](https://github.com/IdeaSpaces-xyz/idea-explorer/releases/tag/handover-2026-10-07) (choose the `.zip` under **Assets**).

## Install on a Mac

1. Download the zip and double-click it to unpack **IdeaSpaces Handover v3.app**.
2. Move the app to **Applications**.
3. On the first open, right-click the app in Applications and choose **Open**, then approve the macOS prompt if it appears. This team build is **not Developer ID signed or notarized**; macOS may warn about it. If macOS does not offer Open, ask us in the Thread rather than turning off your Mac's security settings.
4. In **Start with IdeaSpaces**, choose **Sign in** and use your **ideaspaces.xyz** account in the browser, then return to the app. If you're already signed in on this Mac, you'll see the account menu instead.

You don't need to open a folder to read a Thread. **Your Threads** and **Direct** appear above Create/Open a folder. Open **Direct** first. When a Thread addressed to your exact @handle appears as **new**, open it, read the post and people line, and reply in the field at the bottom. Click **Send reply** once; Enter makes a paragraph and Cmd+Enter sends. A Map attached to a Thread does not grant access to its files.

Questions or trouble installing? **Reply in the Thread where you received the link** so we can work through it together. Don't post account details or passwords in a Thread.

This build has no automatic updater. We'll share a new download when there's a newer build. Developer ID signing and notarization are planned; they are not in this zip.
